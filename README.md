## 📌 О проекте

**Code Executer** - это лёгкий, но функциональный редактор кода, созданный для быстрого написания и выполнения Python-скриптов. Всё в одном окне: редактор с подсветкой синтаксиса, вывод результата и установка библиотек.

### ✨ Возможности

- 📝 Редактор с подсветкой синтаксиса - ключевые слова, строки, комментарии и числа выделены цветом
- 🔢 Нумерация строк - удобная навигация по коду
- 📂 Работа с файлами - открытие, сохранение, создание новых файлов (.py, .txt)
- ▶️ Выполнение кода - запуск Python-скриптов прямо из редактора
- 📦 Установка библиотек - введи название и нажми Install, pip сделает всё сам
- 🎨 Настройка внешнего вида - меняй цвета, шрифты и размер текста
- ⌨️ Горячие клавиши - ускорь работу
- 🔥 Горячая клавиша `\` - мгновенный вызов окна
- 🌙 Тёмная тема - бережёт глаза



## ⚙️ Установка

### Способ 1: Готовый .exe (для обычных пользователей)

1. Скачай последний релиз из раздела Releases
2. Распакуй архив
3. Запусти Code Executer.exe

### Способ 2: Из исходников (для разработчиков)

1. Клонируй репозиторий:
   git clone https://github.com/твой_проект.git
   cd CodeExecuter

2. Установи зависимости:
   pip install -r requirements.txt

3. Запусти:
   python main.py

## 🎮 Как пользоваться

| Действие | Описание |
|----------|----------|
| 📄 New | Создать новый файл |
| 📂 Open | Открыть существующий файл |
| 💾 Save | Сохранить текущий файл |
| 💾 Save As | Сохранить как... |
| ▶ Run | Выполнить код |
| Clear | Очистить вывод |
| pip install + Install | Установить библиотеку |
| \ | Открыть/показать окно |

### ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Ctrl + N | Новый файл |
| Ctrl + O | Открыть файл |
| Ctrl + S | Сохранить файл |
| Tab | Вставить 4 пробела |
| Shift + Tab | Удалить 4 пробела |
| Enter после : | Авто-табуляция |
| \ | Открыть Executer |

## ⚙️ Настройки

В настройках можно изменить:

- 🎨 Цвет фона - подбери идеальный оттенок
- 📝 Цвет редактора - фон для написания кода
- 📤 Цвет вывода - фон для результатов
- ✏️ Цвет текста - цвет шрифта
- 🔤 Шрифт - выбери из 6 вариантов
- 📏 Размер шрифта - от 8 до 24

Все настройки сохраняются автоматически в файл settings.json
